## TL-REV-001

**Document has incremental updates** (structure, info)

The PDF was saved more than once: later revisions were appended to the original file. Linearisation markers are not counted.

*Known false positives:* Very common. E-signature services, form filling and many PDF tools append revisions. Informational only.

## TL-REV-002

**Later revision rewrote page content** (structure, high)

A revision after the first one replaced the content stream of an existing page, so the visible text or graphics were changed after the document was first produced.

*Known false positives:* Rare in genuine documents. Some tools rewrite pages when adding stamps or watermarks; check the changed page for a stamp.

## TL-REV-003

**Later revision added fonts to an existing page** (structure, medium)

A revision after the first one added font resources to a page that already existed. Editing text usually brings in a new font subset.

*Known false positives:* Form filling can add fonts for field appearances; this is suppressed when a valid signature classifies the change as form filling.

## TL-REV-004

**Later revision added or removed pages** (structure, medium)

The number of pages changed in a revision after the first one: pages were inserted, appended or deleted after the document was produced.

*Known false positives:* Appending a signature page or an attachment page in a later save.

## TL-SIG-001

**Signed and unmodified since signing** (structure, info)

A digital signature covers the document and no changes were made after signing. This is supporting evidence that the signed content is intact.

*Known false positives:* The signer's identity is not verified against a trust list; this rule only concerns integrity.

## TL-SIG-002

**Changes after signing are not permitted** (structure, high)

The document was changed after it was digitally signed, and the changes go beyond form filling, annotations or long-term-validation updates.

*Known false positives:* Unusual workflows (for example, re-saving a signed file in an editor) trigger this rule; either way the signed version differs from the file you received.

## TL-SIG-003

**Signature integrity check failed** (structure, high)

The bytes covered by a digital signature no longer match the signature.

*Known false positives:* Corrupted downloads can also break signatures. Obtain the file again from the source.

## TL-SIG-004

**Permitted changes after signing** (structure, low)

The document was changed after signing in a way the signature allows (form filling, annotations or validation data).

*Known false positives:* Normal for forms and multi-party signing.

## TL-META-001

**Editing tool recorded in metadata** (structure, medium)

The Producer, Creator or XMP history names a general-purpose PDF editor or online PDF service, which is unusual for documents issued by banks or institutions. Medium for statements and invoices, low for other documents.

*Known false positives:* People legitimately compress, merge or design PDFs with online tools. Weak on its own.

## TL-META-002

**Metadata dates disagree** (structure, low)

The creation or modification date in the document information dictionary differs from the XMP metadata by more than a day.

*Known false positives:* Time-zone handling and tools that update only one metadata store cause this.

## TL-META-003

**Modified before it was created** (structure, medium)

The recorded modification date is earlier than the creation date, both as written and after time-zone correction.

*Known false positives:* Incorrect system clocks, and files converted long after their last edit. Dates that only look reversed because a tool labelled local time with the wrong zone are ignored.

## TL-META-004

**Producer changed between revisions** (structure, low)

Different revisions of the file were written by different software.

*Known false positives:* Signing and form-filling software records its own producer.

## TL-ID-001

**Permanent document ID changed between revisions** (structure, medium)

The first part of the trailer /ID, which should stay constant for the life of a document, differs between revisions.

*Known false positives:* Some tools regenerate IDs on every save.

## TL-EDIT-001

**Acrobat text-edit markers present** (content, high)

The page contains /TouchUp_TextEdit marked-content sections, which Adobe Acrobat inserts when text is edited by hand.

*Known false positives:* Genuine documents occasionally pass through Acrobat for corrections; the marker shows that text was edited, not by whom.

## TL-FONT-001

**Same font embedded as several subsets** (content, medium)

On one page, the same base font appears under two unrelated subset prefixes that share characters (for example ABCDEF+Arial and GHIJKL+Arial), which happens when an editor embeds the font again to retype text. Medium when the extra subset holds a few digits (a retyped amount), low otherwise.

*Known false positives:* Design and print workflows (Adobe, macOS Quartz, TeX) repeat subsets when they place artwork. Subsets numbered by one producer (LibreOffice BAAAAA, Microsoft Office BCDEEE) are ignored.

## TL-FONT-002

**Font used only for a few characters** (content, medium)

A font is used for only a handful of characters on a page (often digits), while the surrounding text of the same style uses another font.

*Known false positives:* Symbols, bullets and signatures legitimately use separate fonts; digits-only runs are weighted higher. Bold or italic cuts of the page's own typeface (totals) are ignored.

## TL-OVL-001

**Filled shape covers text** (content, medium)

Text is hidden under a later filled shape (including white boxes drawn as paths), or an amount is overprinted by a different amount. Medium when a short piece of text is patched out by a box that hugs it and similar text is drawn in its place; other hidden text is reported as low.

*Known false positives:* Panels, pictures and backgrounds placed over text in slides and designed pages (reported as low), and redaction boxes.

## TL-OVL-002

**Annotation placed over page text** (content, medium)

A FreeText, Square or Stamp annotation overlaps existing page text.

*Known false positives:* Reviewer comments and approval stamps.

## TL-OVL-003

**Invisible text on a page without a scanned image** (content, low)

Text is drawn in invisible render mode on a page that has no full-page image, so it is not an OCR layer.

*Known false positives:* Accessibility tags and search helpers.

## TL-GEO-001

**Amount out of line with its row** (geometry, medium)

An amount sits slightly (0.6 to 2 pt) above or below the baseline shared by the other words of its table row, a typical trace of a value retyped into place.

*Known false positives:* Cells aligned differently on purpose. Prose, and pages where many values are off by varied amounts (an uneven layout), are not checked.

## TL-GEO-002

**Inconsistent typeface or size in a column of values** (geometry, medium)

A value is rendered in a different typeface, or at a different size, from the other values in the same column. The page's own font decides which values are foreign, so a forger who retypes most of a column is still the one highlighted.

*Known false positives:* Totals rows styled differently on purpose.

## TL-IMG-001

**JPEG block grid broken in a region** (image, medium)

The 8x8 compression grid of a JPEG image is misaligned or missing in one region, which happens when content is pasted in from another image. In PDFs only images of paper (scans) are checked, and the finding is a low-severity hint.

*Known false positives:* Heavy recompression can erase the grid everywhere. Scanning and PDF software also recompress parts of a page, which is why the rule is only a hint inside PDFs.

## TL-IMG-002

**Duplicated image region** (image, medium)

Two regions of the image are near-identical copies after excluding repeated characters, a trace of copy-move editing. Only wide bands and blocks are found: a copied word or a narrow column is missed.

*Known false positives:* Logos and repeated form elements; identical glyphs are suppressed, and copies moved only sideways along a line are low-severity hints.

## TL-LOGIC-001

**Running balance does not reconcile** (logic, high)

On a bank statement, previous balance plus credits minus debits does not equal the stated balance on one or more rows.

*Known false positives:* Statements with pending transactions or multi-currency rows; the detector skips rows it cannot parse.

## TL-LOGIC-002

**Invoice totals do not add up** (logic, high)

Line items, tax and discounts do not sum to the stated subtotal or total.

*Known false positives:* Rounding rules; differences of up to two minor units (0.02) are ignored.

## TL-LOGIC-003

**Transaction date outside statement period** (logic, medium)

A transaction is dated before the statement period starts or after it ends.

*Known false positives:* Value-dated transactions; a one-day tolerance is applied.

## TL-LOGIC-004

**Invalid IBAN checksum** (logic, medium)

An IBAN printed in the document fails the ISO 13616 mod-97 check.

*Known false positives:* OCR or copy errors in the source text.
